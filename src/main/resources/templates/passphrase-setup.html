Passphrase für die lokale Anwendung einrichten

Bevor Sie Steuerdaten speichern, muss die Anwendung mit einer lokalen Passphrase geschützt werden.

Verwenden Sie mindestens 12 Zeichen.

Wichtiger Hinweis

Wenn Sie diese Passphrase verlieren, können gespeicherte Steuerdaten nicht wiederhergestellt werden.

Ein späteres Ändern der Passphrase wird erst in einem folgenden Ausbauschritt unterstützt.
